# Lab output captures

`tools/vm.sh cap NAME 'snippet'` writes here. Each file records the snippet and
its real output from the lab VM, so a lesson's `<pre class="out">` blocks can be
pasted from a file rather than retyped — and so a later session can tell whether
a surprising line was actually observed or was written from memory.

Not a build input. Safe to delete; regenerate by re-running the snippet.
